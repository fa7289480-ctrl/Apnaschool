# ApnaSchool Super Admin UI concept

This project includes the responsive ApnaSchool Super Admin dashboard in `src-modern/index.html`.

## Important
- This is a **UI-only preview**, not a connected ApnaSchool SaaS backend.
- Metrics are shown as em dashes and sample rows are explicitly labelled as examples; do not use them as real school data.
- Search filters the sample rows in this preview only.
- Quick actions show explanatory messages and do not create, approve, or modify records.
- Before production, integrate this page with the existing ApnaSchool APIs and preserve server-side authentication, role checks, and school isolation.

## Run ApnaSchool
Use the existing package scripts documented in `package.json`. The Super Admin dashboard is `src-modern/index.html`.
